# Telecom-Gis

##  Project Overview
A web-based Geographic Information System (GIS) platform for managing Cameroon's telecom infrastructure.

##  What's Working Now
- **User Authentication System** with PostgreSQL database
- **Login/Register** pages with form validation
- **Protected Dashboard** with role-based access
- **PostgreSQL Database** storing user data securely
- **JWT Token-based authentication**

##  Tech Stack
- **Frontend:** React, TypeScript
- **Backend:** Node.js, Express, TypeScript
- **Database:** PostgreSQL
- **Authentication:** JWT, bcrypt

##  Getting Started

### 1. Start Backend
cd backend
npm install
npm run dev

### 2. Start Frontend
npm install
npm start
